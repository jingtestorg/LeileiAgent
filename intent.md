# Location-Weather Personalized Greeting Agent

A Python AI agent that greets users with personalized hello messages based on their current location and local weather conditions.

## Business challenge

Build an AI agent that detects or accepts a user's location, fetches current weather data for that location, and responds with a contextually appropriate, personalized greeting (e.g., "Good morning, Berlin! It's a sunny 22°C today — enjoy your day!").

## Key Milestones

1. **Location Input Accepted** — Agent receives and parses a city name or coordinates from the user.
2. **Weather Data Retrieved** — Agent successfully fetches current weather for the given location via a weather API tool.
3. **Greeting Generated** — Agent composes a personalized, context-aware greeting combining location and weather data.
4. **Response Delivered** — The greeting is returned to the user in natural language via the A2A interface.

### Key findings
- No native SAP weather API exists; a public free weather API (e.g. Open-Meteo) will be used as a tool.
- Location can be provided by the user as free text (city name) or inferred from context.
- The agent will use Python tool calls to fetch weather data and compose the greeting.
- SAP Customer Data Platform and Emarsys offer personalization capabilities but are not required for this demo scope.
- The solution is a standalone AI agent with no SAP backend dependency required for the MVP.
- Intelligent Selling Services for SAP Commerce Cloud offers contextual real-time personalization which is conceptually aligned.
